# OmniAffiliateOS — Omnichannel Affiliate Marketing OS

This repository hosts an original, policy-aware affiliate marketing operations platform. The product is designed for evidence-backed offer research, compliant content production, consented lead capture, authorized publishing, attribution, commission reconciliation, and reviewable learning loops.

## Safety and capability contract

- Provider availability is not account authorization. A configured adapter is not considered connected until authenticated health checks succeed.
- Paid spend, publishing, merchant/affiliate applications, emails, and other external side effects must pass authorization, budget, policy, idempotency, and audit gates.
- Drafts and dry-runs are the defaults. Provider workflows that require owner approval, KYC, or unsupported APIs remain explicitly pending/manual.
- Do not store credentials in source control. Use GitHub Actions secrets or deployment secret storage.
- This repository is public. Do not place non-public credentials, private customer data, or proprietary third-party code here. Review upstream licenses before importing reference material.

## Development status

This repository is being built incrementally. A feature is only release-ready when implementation, API/data/UI contracts, authorization, tests, CI evidence, and provider prerequisites are documented. No earnings, platform approval, or production deployment is guaranteed by the code alone.

See `docs/IMPLEMENTATION_STATUS.md` and `docs/REQUIREMENTS_TRACEABILITY_MASTER.md` for evidence-based status once the build is populated.
