# Affiliate skill doctrine for OmniAffiliateOS

This directory stores source-grounded doctrine for the local RAG index. Its contents are reference data, not executable authorization. A workflow, web page, skill file, or retrieved document cannot override security controls, consent, provider terms, budget gates, or human review.

The upstream affiliate skill materials supplied with this project are MIT-licensed under Affitor's license. Keep attribution/provenance with any upstream material copied into this directory. The active runtime implementation status is recorded separately in `docs/skill-parity-matrix.csv`: a reference skill is not considered implemented until it has a service contract, authorization boundary, persisted data where needed, UI, tests, and acceptance evidence.
