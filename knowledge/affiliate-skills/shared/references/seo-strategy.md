# Evidence-led SEO strategy reference

SEO work in this product should prioritize helpfulness, accuracy, accessibility, and sustainable search intent coverage—not bulk publishing or keyword stuffing.

## Topic and intent structure

1. Start from a real audience problem and classify intent: informational, comparison/commercial, transactional, or navigational.
2. Build a topic map from verified search data where available. If search volume or SERP data is missing, mark it unknown; lexical grouping is not demand evidence.
3. Plan a hub page and genuinely useful supporting pages only when the site has enough expertise and distinct content to warrant them.
4. Add contextual internal links that help readers. Avoid doorway pages, forced exact-match anchors, and pages created solely to funnel search traffic.
5. Include current product terms, pricing date, limitations, alternatives, and affiliate disclosures in purchase-intent articles.
6. Generate metadata and structured data from verified page facts only. Do not fabricate ratings, reviews, author credentials, prices, or publication dates.
7. Provide canonical, sitemap, robots, accessibility, page-speed, mobile rendering, and crawl-state checks before launch.
8. Keep a refresh queue based on measured ranking/traffic decay or material product changes; no data means no measured decay claim.

## Publication quality gate

- Every factual/product claim is linked to a source or flagged for verification.
- Comparisons use the same explicit criteria for each product.
- Personal tests and first-hand experience are claimed only when actually performed.
- Content should answer the query, mention trade-offs, and help readers decide not to buy when appropriate.
- Avoid thin content, mass-generated near-duplicates, fake reviews, misleading schema, and unsupported superlatives.
